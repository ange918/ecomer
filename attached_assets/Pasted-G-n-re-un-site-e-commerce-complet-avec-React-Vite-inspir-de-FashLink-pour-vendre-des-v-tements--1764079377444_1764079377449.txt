Génère un site e-commerce complet avec React + Vite, inspiré de FashLink, pour vendre des vêtements : pantalons, chemises, tee-shirts, casquettes.

🔵 SPÉCIFICATIONS

Pages

Accueil (index) : Hero, collections, catégories, nouveautés, bestsellers, promo, newsletter

Boutique (shop) : grille produits, filtres (catégorie, taille, prix), recherche

Page produit : image, description, taille, couleur, bouton ajouter au panier

Panier (cart) : liste articles, modifier quantité, total, stockage localStorage

À propos : histoire de la marque, galerie, vidéo Instagram/YT

Contact : formulaire + infos

Dashboard Admin : login + gestion produits
